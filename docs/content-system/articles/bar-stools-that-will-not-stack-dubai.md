The stools are tall, and they will not stack. Count the ones that are leaving, write “will not stack” on the same note, and measure one stool as it stands. A booking that says “the dining chairs” will be read as chairs from a table. This note is the bar stools.

A dining table, its top and the chairs that leave with that table stay on the [dining-table guide](/blog/dining-table-removal-dubai). Dining chairs that leave while the table stays are the [dining-chairs note](/blog/dining-chairs-without-the-table-dubai). An adult armchair, including a recliner, stays on the [armchair guide](/blog/armchair-removal-dubai). A whole balcony, with pots, a table and mixed outdoor pieces, stays on the [balcony clearance](/blog/balcony-clearance-dubai). Come back here when the pieces are bar stools and the open question is that they will not stack.

## Count the stools that will not stack

Stand where you can see each stool that belongs to this set, including a stool that has been moved to another room. Count them out loud. Write the number, then write how many of that number are leaving. “Four stools, four leaving” is a count. “The stools” is not. “Three leaving, one staying” is a count as well. A stool you are keeping must be obvious in the note and absent from the leaving photograph.

Give each leaving stool a name you can point at if they are not identical. “Stool with the torn seat”, “stool with the short footrest”, “stool stored on the balcony”. If they match, you may count them as a number and still photograph them so the number can be checked. A photo of one stool does not describe a crack on another.

If a stool is staying, say so. Do not stand the keeper in the doorway you will later measure. If you cannot tell which stools are leaving, you are early. Decide, then count again.

Look under the counter and along the wall. A stool pushed in is easy to miss. A stool used at a desk in another room is still this set if it is one of these tall stools and it is leaving. Write the room it is in now. Do not assume the person reading the note will search the flat.

These stools will not stack. Write that in the first line, not as a footnote. “Will not stack” means you have tried only if they were made to stack, and they do not lock, or you can see they have no stacking feature. A footrest, a back, a swivel or a splayed leg is a reason they may not nest. Say which of those you can see. Do not build a pile by balancing seats on seats and then call it a stack. A pile that falls is not a stack. Leave them separate.

If someone has already tied them together with a strap, untie them so each stool can be counted. If they were built to hook together and the hook releases by hand, you may separate them and write “unhooked”. If they will not separate, write “still hooked” and count the number you can see, not one object.

A stool that is already outside the flat, in a store or on a balcony, is still a stool in the count if it is leaving from this address. Name the place. Do not leave it out because it is not at the counter today.

## What each stool is

Look at one leaving stool at a time. Say what you can see: a timber seat, a metal frame, a plastic seat, a padded seat, a back, or no back. You do not need a brand. You do need the thing that changes the carry.

The height is the point of a bar stool. Measure from the floor to the top of the seat, as it stands, and measure the overall height if there is a back. Write both if they differ. If the stools differ, measure the tallest and the widest and say which names those are. A shorter stool does not prove the tall one will pass a door. If you have no tape, write “not measured”. Do not invent the numbers. This page does not keep a standard door size.

A footrest ring, or a footrest bar, sticks out. Measure across the footrest if it is wider than the seat. Write “footrest”. If the footrest is loose, write “footrest loose” and say which stool. Do not bend it off to make the stool narrower. Do not saw it.

A back makes the stool taller. If the back is part of the frame, it stays. If a back pad lifts off by hand, you may lift it off, keep it with that stool, and write “back pad off”. If it is fixed, write “back fixed”. Do not unscrew a back because a shorter stool would be easier to describe.

A swivel seat turns. Write “swivel”. If the stool also rises on a gas lift, write “gas lift” and leave the lever alone. Do not open the column. Do not cut a hose or a cable you cannot see a reason to name. If the seat is stuck at a height, write the height it is stuck at. Do not hit the lever.

A stool with a foot ring and a fixed height is not a gas-lift stool. Say which you have. Mixing the two in one count, without saying so, makes the tallest one invisible.

Look at the base. Four legs, a pedestal with a round foot, or a sled base. Write what you see. If a glide is missing, write “glide missing” and say which leg. If the stool rocks, write “rocks”. Do not book it as standing level.

A wooden stool with a hard seat is one line. If a joint wobbles, write “wobbles”. If a leg is cracked, write “leg cracked” and say which leg as you look at the stool. Do not pull a cracked leg off to make the stool shorter. If the stool will not stand, write “will not stand” and say how it rests.

An upholstered seat changes the stool. A tear, a stain or a sag is part of the description if you can see it. Write what you see. A loose pad is not the same as a seat that is fixed. If the pad lifts off, set it with that stool and write “pad off”. If it is fixed, write “pad fixed”.

If a stool plugs in, stop and say so. A powered seat is not a plain bar stool. Name the cable. Unplug it only at the wall, coil the cable, and write “unplugged”. Do not cut the cable.

Look at the feet before you slide a stool. Felt pads, plastic glides and bare metal mark the floor in different ways. If a glide is loose in your hand, bag it with that stool or press it back only if it already fits. Write “glide loose” if it will not stay. This page does not promise the floor will be unmarked. It asks you to say what the feet are.

If a stool is broken into pieces already, count the pieces with that stool. “Seat, column and base, one stool, already apart” is honest. A pile of unnamed metal is not a count. Keep the pieces of one stool together.

## Why they will not stack

Look for a stacking feature before you decide the sentence. Some stools have a frame that nests, or a seat that accepts the foot of the next stool. If you can see that feature and it works with your hands, you may stack them, write “stacks”, and say how many are in the stack. Photograph the stack from the side so the number is visible. This page is for the set that will not do that. If they stack, you are describing a different job, and you should not use “will not stack” in the note.

If there is no nesting frame, write “will not stack” and leave them separate. A back, a footrest, a swivel or a wide base is enough reason. You do not need to prove it by building a pile that falls.

Do not remove a back, a footrest or a seat to force a stack. Do not tie four stools into one bundle and call the bundle one item. A strap you add can hold them for a moment and then slip. The count is the number of stools. The bundle is not a new object.

Do not lay them on their sides in a stack unless they were made to travel that way and you can say so from a label you can see. A gas-lift stool on its side is still a gas-lift stool. Write “gas lift, left upright” if you are leaving it upright. If you have laid it down because it will not stand, write “laid down, will not stand” and name that stool. Do not open the lift.

If the stools are different heights, they will not make one neat column even if one of them nests. Write the heights. The tallest one is the one to measure against the door. The widest base is the one to measure across.

A stool that folds, and whose hinge already closes with your hands, can be folded. Write “folded”. If the hinge will not move, write “will not fold” and leave it open. Do not hit the hinge. Do not saw a tube. A folding stool that folds is not the same sentence as “will not stack”. Say both if both are true: “folds, and will not stack with the others”, or “will not fold, will not stack”.

Look under the seat before you call the stool empty. A menu, a toy, a charger. If you are keeping them, they leave the photograph. If something is leaving and it is not the stool, name it or take it out of the shot.

A cover that zips off can come off if you want it off. Bag it with the stool and write “cover off”, or leave it on and write “cover on”. If the zip will not move, leave the cover. Do not cut the fabric.

## The height against the doorway

Walk the path the stools have to take. Open each door as far as it opens. The clear width is the gap you can see, and the clear height is the gap under the head of the frame if the stool is travelling upright. A rug in the opening is part of the width until you move the rug. Move what you are keeping, then look again.

A bar stool is tall. If it will not fold and it will not stack, it travels at the height you measured. Measure that height against the doorway. If the stool is taller than the clear opening, write both figures, or write “taller than the opening” if you can see that and you have no tape. Do not invent a door size. Do not saw the back to win the comparison.

Name the door that limits the stools. If a second door is tighter, name that one too. A stool that leaves the kitchen and stops at the front door has not left. If you have already been given a lift instruction, add it: which lift, and the note you were given. If you have no lift note, write “no lift instruction yet”. Do not invent a lift size.

If the stools stand at a kitchen island, the island is not a door. You walk them out from the counter. Do not unscrew the island. Do not describe the counter as part of the stool. Write “stools at the island” if that is where they are, and “island staying” if the counter is staying. A breakfast bar that is a fixed worktop stays. The stools are the loose seats.

If a stool is on a balcony, it still has to come through the balcony door and then through the flat. The balcony clearance is the whole outdoor load. Use it when pots, a table and mixed pieces are leaving together. Use this page when the stools are the pieces and the rest of the balcony is staying. Name the balcony door if it is the tight one. Do not lower a stool over the railing. Do not leave the stools in a shared corridor overnight as a way to clear the kitchen. The corridor is not the gap you photographed.

The dining-table guide remains the table and the chairs that belong to it. A stool that is not part of that table, and that will not stack, stays here. Do not add the stools to a dining-chair count to make a set look complete.

## What is not this set

A dining chair has a back and a seat at table height, and it belongs with a dining table. Those chairs, when they leave with the table, stay on the dining-table guide. Those chairs, when the table is staying, stay on the dining-chairs note. A bar stool is taller, and it is this page when it will not stack. If you are unsure, look at the seat height and the footrest. A chair you sit at a dining table, with your feet on the floor and no footrest, is not a bar stool.

An armchair has arms, a back and a seat at lounge height. A wingback, a swivel base that belongs to a lounge chair, and a recliner stay on the armchair guide. A bar stool that swivels is still a bar stool. Do not call it an armchair because the seat turns.

A high chair has a child’s seat, a tray or the place a tray clipped, and a frame built for a child. That chair is not a bar stool. If it is leaving, it has its own line. Do not add it to this count.

A counter stool and a balcony stool can be this page if they are the tall seats that will not stack. Write the word you use in the house, and the height. A low stool, a footstool or an ottoman is not this set. Name it on its own if it is leaving, or leave it. Do not add it to the bar-stool number.

An office chair on wheels is not a bar stool. Name it as an office chair if it is leaving, or leave it. This page will not become that chair.

A bench at the counter is not a stool. If the bench is leaving, write “bench, separate” and say whether it is one piece. Do not hide a bench inside the stool count.

A whole children’s room, a whole dining set, or a whole balcony of furniture is not four bar stools. If the only objects from the balcony are these stools, you may count them here and say they are on the balcony. If the balcony is being cleared, use the balcony list. Do not turn this note into the balcony.

A stack of identical chairs from a waiting room, or a restaurant floor of banquet chairs, is not this set. This page does not cover those rooms. If the seats are tall stools in a home, and they will not stack, you are in the right place. If they are a commercial run of chairs, you are not. This page does not give that commercial run a URL.

Whether another household could use a sound stool is not decided here. This page does not add a test or a standard. If you have decided the stools are leaving, the count and the stack are the work. If you have not decided, do not book them.

If a tenancy list or a written note says the stools stay with the property, leave them off the booking. A worn seat is not permission. The person who may release them writes that release. This page does not interpret a contract.

A stool you are moving to another address to keep using is not a collection. This note is for stools that are leaving the property.

## One line in the booking

You can ask for [furniture collection for the stools](/services/furniture-removal) once the number leaving is written, each stool is still a stool rather than a forced pile, and the note says they will not stack. That page is the furniture leaving the room. It is not a request to saw a back off, and it is not a request to make the stools nest.

If other household items are leaving in the same visit, and they are not these stools, say so as separate lines. Do not hide a dining table, an armchair or a balcony set inside the stool count. Those lines are not this set.

Say, in one message:

- how many bar stools are leaving, and how many are staying
- the room, and a stool that is on a balcony or in another room
- seat height, and overall height if there is a back
- footrest, swivel, gas lift, or a fixed frame
- will not stack
- folded, will not fold, or not a folding stool
- a crack, a wobble, a missing glide or a loose footrest, if you can see it
- the clear height and width of the doorway that limits the tallest stool
- anything that is not this set: a dining chair, an armchair, a high chair, a bench

Do not write “the dining chairs” as the only words. Do not write “will not stack” if you have since found that they nest and you have stacked them. Do not ask for a stool to be cut because the figure is larger than the gap. The figure is the report.

If the stools are still mixed with the ones you are keeping, you are early. Separate them, or name the keepers. Send the count you can stand in front of and check.

The dining-table page remains the table and the chairs that leave with it. The dining-chairs page remains the chairs that leave while the table stays. The armchair page remains an adult lounge chair. The balcony page remains the whole balcony. This page remains the bar stools that will not stack.

## The morning the stools leave

Count them again. If someone moved a keeper into the leaving group, take it out and correct the number. If a leaving stool was pushed back under the counter and you still want it to go, it is still leaving. Check the name matches the stool.

Look at the stack you did not make. They should still be separate. If someone has piled them and the pile is unstable, separate them again and leave the note as “will not stack”. If you have discovered that they do nest, change the note. Do not send “will not stack” for a set you have since stacked on purpose.

Open the door to the gap you measured. A box in the opening changes the width and the height. Move it before you treat the old figure as current. If the tallest stool is a different stool from the one you measured, measure again or say which stool is now the tall one.

Point at the leaving stools as the stools. Point at a dining chair, an armchair or a high chair only if it has its own line. Leave a bench and an office chair out of the stool count unless you have named them as separate lines.

Do not line the stools along a shared corridor the night before. If the only place they can wait is the room they are already in, leave them there, clear of the doorway, upright if they stand, with the keepers obvious.

When they have gone, look under the counter. A pad you meant to include is still a pad if it is on the stool you are keeping. A stool you meant to keep is a problem only if it left. The useful record is the sentence from the first count: the stools that were leaving, the stools that were staying, the words “will not stack”, and the tallest stool’s height written beside the doorway.
